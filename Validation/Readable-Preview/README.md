Date: October 20, 2026. Parent source checkpoint: 404ae43.

## Scope

The current View selector above the canvas offers Edit layout, temporary Isolate
selection and diagnostic All layers. New skins default to Edit layout. Unknown
visibility is hidden unless Show hidden is explicitly enabled. Unresolved
ordinary text/button/checkmark captions use short examples while their property
fields, expressions and audit uncertainty remain intact. Actual sample values,
literal and empty text are preserved. This does not resolve plugin conditions.

MediaTipOverlay.xml / window 7979 is recognized only with its unique label
headline and five complete canonical five-line ID blocks (20–24 through 60–64).
A headline text edit does not disable recognition. Music/Video/Pictures/Folder/
Radio show one corresponding block and related artwork. Shared background/
headline remain; All layers deliberately restores the authored overlap. Sample
metadata is presentation-only and never inserted into PreviewSettings.Values,
XML or exports. Other pages/plugins/incomplete shapes are not automatically
grouped. Generic isolation provides a bounded editing aid for those pages.

Isolation follows the selected control and runtime/source descendants, bypassing
visibility/editor hiding only for this temporary view. Active collection
subview constraints remain. It clears on page/theme/session changes and is not
saved as a selected-element reference. View and example mode are validated and
saved as editor metadata, participate in unsaved-state signatures and cannot
change XML Undo/Redo or export bytes. Legacy projects without these attributes
retain diagnostic versus clean intent. Existing BasicHome/media-folder presets
explicitly return to Edit layout.

```powershell
.\Validation\Package-Readiness\Run-Probes.ps1 `
  -PackageZip C:\review\MP1-Skin-Studio-Review.zip `
  -OutputDirectory C:\review\readable-preview -SkipFullUi -IncludeCore `
  -ReadablePreviewSkinDirectory 'C:\ProgramData\Team MediaPortal\MediaPortal\skin\DefaultWideHD'
```

OutputDirectory. It compiles against the chosen executable; generated projects,
ZIP and synthetic renders stay in its own output folder. Installed XML is read
and hashed, never rewritten.
